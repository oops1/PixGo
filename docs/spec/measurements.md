# Замеры мокапов

Координаты — пиксели PNG мокапа, включительно; окно = весь PNG. Инструмент — `px.exe` (crop/ink/row/col). Значения — эталон вёрстки при размере окна, равном мокапу; при другом размере правила привязки указаны в столбце «Привязка».
